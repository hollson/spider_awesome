## 一、项目概述

### 1.1 项目定位

**Spider Awesome** 是一个基于分层架构的**通用数据采集模板项目**，适用于：

- 🌐 **网站数据采集**：商品信息、新闻资讯、社交内容
- 🔌 **API 接口对接**：第三方数据源、开放平台接口
- 📁 **文件数据处理**：CSV、JSON、XML 等格式文件
- 📊 **定时数据同步**：数据库同步、数据仓库更新

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| 🏗️ **分层架构** | 采集 / 处理 / 存储 / 调度四层独立，职责清晰 |
| 📡 **自动发现** | 采集器 `source_*.py` 自动注册，无需手动配置 |
| 🗄️ **多数据库** | 统一 `DATABASE_URL`，支持 SQLite / PostgreSQL / MySQL |
| ⏰ **独立调度** | 每个采集器可配置独立的 cron 调度时间 |
| 🔄 **并发控制** | 线程池并行采集，支持失败重试 |
| 🌍 **环境隔离** | dev/test/prod 三套配置，零代码切换 |
| 🛠️ **生产级工具链** | UV 依赖管理，Ruff 代码质量，Loguru 日志 |

### 1.3 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.12+ |
| HTTP | Requests + 自定义重试/代理/超时 |
| 解析 | BeautifulSoup4（HTML）、json（JSON） |
| 数据库 | SQLAlchemy 2.0（ORM） |
| 调度 | APScheduler |
| 日志 | Loguru（按天轮转） |
| 配置 | python-dotenv + PyYAML |
| 校验 | Pydantic 2.0 |
| 工具 | UV（依赖）、Ruff（代码）、Bandit（安全） |

## 四、核心模块详解

### 4.1 采集层 `src/collector`

#### 基类设计

```python
# base_collector.py
class BaseCollector(ABC):
    @property
    def name(self) -> str:
        """采集器名称"""
        raise NotImplementedError

    def fetch(self) -> list[dict[str, Any]]:
        """执行采集，返回数据列表"""
        raise NotImplementedError

    def read_cache(self, filename: str) -> str | None:
        """读取缓存文件"""

    def write_cache(self, filename: str, content: str) -> None:
        """写入缓存文件"""

    def fetch_with_cache(self, cache_filename: str, fetch_func) -> str:
        """带缓存的采集"""
```

#### 自动发现机制

`registry.py` 自动扫描 `source_*.py` 文件，无需手动注册：

```python
# 自动发现逻辑
def _discover_collectors() -> dict[str, type[BaseCollector]]:
    collectors = {}
    for file_path in Path(__file__).parent.glob("source_*.py"):
        name = file_path.stem.replace("source_", "")
        module = importlib.import_module(f"src.collector.{file_path.stem}")
        # 找到 *Collector 类
        for attr_name in dir(module):
            attr = getattr(module, attr_name)
            if isinstance(attr, type) and issubclass(attr, BaseCollector):
                collectors[name] = attr
    return collectors
```

### 4.2 处理层 `src/processor`

#### 清洗器 Cleaner

```python
class Cleaner(BaseProcessor):
    def process(self, records: list[dict]) -> list[dict]:
        # 1. 去重（基于 ID）
        records = self._deduplicate(records)
        # 2. 过滤空值记录
        records = self._filter_empty(records)
        # 3. 清理字符串字段
        records = self._clean_strings(records)
        return records
```

#### 校验器 Validator

```python
class Validator(BaseProcessor):
    def process(self, records: list[dict]) -> list[dict]:
        valid_records = []
        invalid_records = []
        for record in records:
            try:
                validated = DataRecordSchema(**record)
                valid_records.append(validated.dict())
            except Exception as e:
                invalid_records.append((record.get("id"), str(e)))
        return valid_records
```

```python
def run_collector(collector_name: str) -> dict[str, Any]:
    """执行单个采集器任务"""
    # 1. 采集
    collector = get_collector(collector_name)
    records = collector.fetch()
    # 2. 清洗
    records = Cleaner().process(records)
    # 3. 校验
    records = Validator().process(records)
    # 4. 存储
    saved = MySQLStorage(auto_create=True).save(records)
    return {"total": len(records), "success": saved}
```

## 七、扩展开发

### 7.1 新增采集器

**Step 1: 创建文件**

```python
# src/collector/source_mymusic.py
from src.collector.base_collector import BaseCollector
from src.common.logger import logger

class MyMusicCollector(BaseCollector):
    """音乐数据采集器"""

    API_URL = "https://api.example.com/music"

    @property
    def name(self) -> str:
        return "mymusic"

    def fetch(self) -> list[dict]:
        logger.info(f"[{self.name}] 开始采集")

        # 1. 获取数据（带缓存）
        content = self.fetch_with_cache(
            cache_filename="mymusic_raw.json",
            fetch_func=self._make_request,
        )

        # 2. 解析数据
        data = json.loads(content)
        records = [self._parse_item(item) for item in data["items"]]

        logger.info(f"[{self.name}] 采集完成，共 {len(records)} 条")
        return records

    def _make_request(self) -> str:
        response = self.http_client.get(self.API_URL)
        return response.text

    def _parse_item(self, item: dict) -> dict:
        return {
            "id": self.generate_record_id(item["id"]),
            "source": self.name,
            "collector_name": self.name,
            "title": item["name"],
            # ... 更多字段
        }
```

**Step 2: 添加配置**

```yaml
# configs/collectors.yml
collectors:
  mymusic:
    enabled: true
    cron: "0 */6 * * *"
    timeout: 300
```

**Step 3: 完成**

```bash
python src/main.py list                    # 看到 mymusic
python src/main.py run --source=mymusic    # 执行采集
```

## 九、常见问题

### Q1: 如何添加新的采集器？

A: 只需在 `src/collector/` 下创建 `source_xxx.py` 文件，继承 `BaseCollector`，实现 `fetch()` 方法即可。无需修改其他代码，采集器会自动发现。

### Q2: 如何为不同采集器设置不同的调度时间？

A: 在 `configs/collectors.yml` 中为每个采集器配置独立的 `cron` 字段：

```yaml
collectors:
  alerion:
    cron: "0 */2 * * *"    # 每 2 小时
  asl:
    cron: "30 0 * * *"     # 每天 00:30
```

### Q3: 如何切换数据库？

A: 修改 `configs/.env` 中的 `DATABASE_URL`：

```bash
# SQLite
DATABASE_URL=sqlite:///var/database/spider_awesome.sqlite3

# PostgreSQL
DATABASE_URL=postgresql://user:pass@host:port/dbname

# MySQL
DATABASE_URL=mysql+pymysql://user:pass@host:port/dbname
```

### Q4: 如何调试采集器？

A: 使用 `--dry-run` 参数试运行，不保存到数据库：

```bash
uv run python src/main.py run --source=alerion --dry-run
```

### Q5: 日志文件在哪里？

A: 默认在 `var/logs/spider_awesome.log`，按天轮转，保留 7 天。可在 `configs/.env` 中配置：

```bash
LOG_FILE=var/logs/spider_awesome.log
LOG_RETENTION=7
```
